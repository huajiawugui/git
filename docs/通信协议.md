# 通信协议(ESP32 ↔ 网页)

## 1. 传输层

| 项 | 值 |
|---|---|
| WiFi 模式 | ESP32 AP(热点),SSID `FishBuoy`,密码 `12345678`,IP `192.168.4.1` |
| WebSocket | `ws://192.168.4.1:81`(主通道,JSON 文本帧) |
| HTTP | `http://192.168.4.1/`(LittleFS 静态网页) |
| 兜底通道 | HTTP `GET /api/status`(1Hz 轮询,返回同 tele 报文);`GET /api/cmd?cmd=...`(WebSocket 不可用时下行) |

## 2. 报文封装

所有帧为 JSON:`{"t": <type>, "v": 1, ...}`(`v` 为协议版本号)。

## 3. 上行报文(ESP32 → 网页)

### tele — 遥测(泳姿中 20Hz,待机 5Hz)

```json
{"t":"tele","v":1,"ts":1700000000,"servo":[96,110,90],"dist_cm":25.4,"gait":"S","obstacle":false,"temp_c":26.5}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| ts | number | 毫秒时间戳 |
| servo | [n,n,n] | 舵机角 [尾, 中, 头],60~120 |
| dist_cm | number | 红外距离 cm;`-1` = 超量程(>80cm)或未标定 |
| gait | string | `IDLE`/`S`/`C_L`/`C_R`/`CPG`/`MANUAL`/`AVOID` |
| obstacle | bool | 是否正处于避障状态 |
| temp_c | number | 水温(可选,无 DS18B20 时省略) |

### event — 事件(状态跃迁瞬间)

```json
{"t":"event","v":1,"evt":"obstacle"}
```

网页收到后闪避障警告条 2s。

### ack — 应答

```json
{"t":"ack","v":1,"id":3,"ok":true}
```

### pong — 心跳应答

```json
{"t":"pong","v":1}
```

## 4. 下行报文(网页 → ESP32)

### cmd:gait — 切换泳姿

```json
{"t":"cmd","v":1,"cmd":"gait","gait":"S"}              // S | C_L | C_R
{"t":"cmd","v":1,"cmd":"gait","gait":"CPG","dir":"fwd"} // dir = fwd | back
```

### cmd:stop — 停止回中

```json
{"t":"cmd","v":1,"cmd":"stop"}
```

### cmd:servo — 手动舵机(切入 MANUAL 模式)

```json
{"t":"cmd","v":1,"cmd":"servo","id":0,"angle":120}   // id = 0尾 / 1中 / 2头
```

### cmd:cpg — 在线调参(字段可缺省,只改传入项)

```json
{"t":"cmd","v":1,"cmd":"cpg","W":3.0,"amp":30,"bias":5,"pb":0.7}
```

| 字段 | 含义 | 缺省行为 |
|---|---|---|
| W | 频率 rad/s | 保持现值 |
| amp | 幅值 度 | 保持现值 |
| bias | 偏置 度 | 保持现值 |
| pb | 方向比例 | 保持现值 |

### cmd:status — 请求立即遥测

```json
{"t":"cmd","v":1,"cmd":"status"}
```

网页在 WebSocket 建立后自动发送一次,用于立即刷新 HUD。

### ping — 心跳(网页每 5s)

```json
{"t":"ping","v":1}
```

ESP32 回 `pong`。

## 5. 连接管理

| 机制 | 参数 |
|---|---|
| 心跳 | 网页每 5s 发 `ping`;ESP32 15s 未收到任何帧判为断连,复位连接状态(舵机保持当前泳姿) |
| 重连 | 网页断线后指数退避 2s → 4s → 8s → … 上限 15s;重连成功立即发 `status` |
| 降级 | 连不上时网页自动进入**内置 DEMO 模式**(本地模拟器驱动 3D 动画),演示不断场 |
| 本地文件 | 以 `file://` 打开网页时直接 DEMO 模式,不尝试连接 |

## 6. 下行节流

- 泳姿按钮:点击即时下发
- CPG/手动舵机滑杆:松开 120ms 后统一下发一次(防抖,避免拖动期间刷爆 50Hz 指令流)

## 7. 完整示例:一次 CPG 调参

```
网页 → ESP32:
{"t":"cmd","v":1,"cmd":"gait","gait":"CPG","dir":"fwd"}
{"t":"cmd","v":1,"cmd":"cpg","W":3.0,"amp":30,"bias":5,"pb":0.7}

ESP32 → 网页:
{"t":"ack","v":1,"id":7,"ok":true}
{"t":"tele","v":1,"ts":1700000123,"servo":[104,113,96],"dist_cm":40.2,"gait":"CPG","obstacle":false}
```

## 8. 与串口调试协议的关系(M2)

固件串口(115200)使用**同构命令集**:`gait S` / `gait C_L` / `gait CPG fwd` / `stop` / `servo 0 120` / `cpg 3.0 30 5 0.7` / `dist 25.4`(SIM 模式注入距离)。串口每 50ms 打印一行 `S=<尾>,<中>,<头> D=<距离> G=<gait>`。串口调通后,WS 协议只是同一解析器的另一种输入来源,联调风险最低。
