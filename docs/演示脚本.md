# 5 分钟答辩演示脚本

## 时间轴(总 5 分钟)

| 时间 | 环节 | 内容 | 道具 |
|---|---|---|---|
| 0:00–0:40 | 开场 | 项目定位:《鱼群智联》无线传输浮标系统;本原型聚焦"感知(红外)→ 决策(泳姿库/避障)→ 执行(舵机)→ 可视化(数字孪生)"闭环 | 网页投屏 |
| 0:40–1:40 | 泳姿演示 | 网页演示模式:① `1` S 形(行波:尾大摆、头微摆);② `2/3` C 形左右转(一次性);③ `4/5` CPG 前进/后退;④ 拖 CPG 滑杆在线调频率/幅值/偏置,3D 鱼即时响应 | 键盘 1~6 |
| 1:40–2:20 | 避障演示 | 距离滑杆拖到 <5cm 或点"模拟障碍物"→ 自动 C 形转向 → 恢复原泳姿;强调滞回(5cm 触发/8cm 解除)+ 2s 冷却 | 网页 |
| 2:20–3:30 | 实物演示 | 真鱼上电:串口遥测正常;S 形游动;手挡红外 → C 转避障并自动恢复;CPG 调参 | 真鱼 + 水池 |
| 3:30–4:30 | 数字孪生 | 手机连热点 FishBuoy → 打开 192.168.4.1:对照真鱼与 3D 鱼同步摆动(遥测 20Hz);手机下发指令遥控真鱼;拔掉手机 WiFi 再连,<3s 恢复 | 手机 + 真鱼 |
| 4:30–5:00 | 总结 | 三个技术点 + 后续方向(见下) | 投屏 |

## 关键话术

**泳姿数据库**
> "S 形行波由 12 步表描述,头领先尾 120°,与真实鱼类一致;C 形转向是 16 步一次性动作;CPG 用三耦合相位振荡器,频率、幅值、偏置三个物理量在线可调——这为后续多鱼协同的相位同步预留了接口。"

**避障**
> "红外测距经 32 次均值滤波与两点标定,5cm 触发、8cm 解除的滞回设计避免临界抖动,2 秒冷却防止连续转向。"

**数字孪生**
> "ESP32 开热点并内置网页,舵机角度与距离以 20Hz 遥测上行,实时映射到 3D 模型;整套系统零外网依赖,现场最稳。"

**总结(三个技术点)**
1. **非阻塞状态机**:全部 millis() 调度、零 delay(),WiFi 服务与泳姿执行互不阻塞
2. **参数化泳姿**:步进表 + CPG 双形态,为多鱼协同控制预留相位同步接口
3. **全本地 WiFi**:AP + LittleFS,手机连热点即用,无外网/无服务器依赖

**后续方向**:LoRa 远距离组网、BLE 短距配对、水声信道仿真对接;多鱼 CPG 相位同步队形;浮标数据回传上位机。

## 应急预案

| 风险 | 应对 |
|---|---|
| 手机浏览器异常 | 换电脑演示网页;真鱼改用**串口命令**演示(串口协议与 WS 同构,见 docs/通信协议.md §8) |
| 舵机扫齿 | 备件 SG90 ×2 现场快换 |
| 红外标定漂移 | 演示前用 docs/标定记录.md 快速两点重标(5 分钟) |
| WiFi 现场干扰 | ESP32 自开热点,不依赖场地网络;手机不行换电脑 |
| 一切失效 | 网页演示模式(断网双击即用)完整走完前三节叙事,真鱼静态展示 |
