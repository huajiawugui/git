# 泳姿数据库(网页与固件共用)

**舵机约定**:`servo[0..2] = [尾, 中, 头]`,90° 为中位,限幅 **60~120°**。
网页 `web/index.html` 与固件 `firmware/gait.cpp`、`firmware/cpg.cpp` 使用**同一套参数表数值**,任一侧改动必须两边同步,并运行 `node web/test/gait_test.js`(14 项断言)回归验证。

## 1. S 形前进(S_MOVE)— 行波步进表

- 12 步 × 50ms = **600ms / 周期**
- 生成公式:`θi(k) = 90 + Ai·sin(2πk/12 + φi)`,幅值 `A = [30, 20, 10]°`,相位 `φ = [+120°, +60°, 0°]`(下标 0/1/2 = 尾/中/头)
- **头领先、波向尾传播**(尾滞后头 120°),与真实鱼类游动一致;尾摆幅 60° > 中段 40° > 头部 20°

## 3. CPG 中枢模式发生器(移植自 RoFish)

三个耦合相位振荡器,分别驱动尾/中/头三段,与 RoFish 的 CPG 类同构:

**相位方程**

```
sA_d[i] = W + Σj w[i][j] · sr[j] · sin(sA[j] − sA[i] − phi[i][j])
```

**幅值收敛**(临界阻尼二阶系统,ar = ax = 20,时间常数 ≈0.1s,约 0.5s 内稳定)

```
sr_dd = ar · ((ar/4)(cR − sr) − srD)
sx_dd = ax · ((ax/4)(cX − sx) − sxD)     ← 偏置同理
```

**输出**:`out_i = sx_i + sr_i · sin(sA_i)`(rad),换算角度后限幅 60~120°。

### 参数

| 参数 | 默认 | 范围 | 含义 |
|---|---|---|---|
| W | 2.5 rad/s | 0.5~6 | 摆动频率(0.4Hz,周期 2.5s;相邻段时滞 0.71/2.5 ≈ **284ms**) |
| amp | 25° | 5~40 | 摆动幅值(收敛目标 cR) |
| bias | 0° | −20~+20 | 偏置 cX:正=左偏,负=右偏(连续转向) |
| pb | 0.7 | 0~1 | 固件端方向控制比例 |
| w | 5 (1/s) | — | 耦合权重(相邻段全耦合) |

### 相位偏置矩阵(前进/后退切换)

```js
// 前进:头领先,波向尾传播
phiF = [[0, 0.71, 1.41], [-0.71, 0, 0.71], [-1.41, -0.71, 0]]
// 后退:取反,波反向传播
phiB = −phiF
```

> 注意:RoFish 原实现的相位偏置方向曾使尾部领先头部;本项目按真实鱼类行波修正为头领先,并做了两层验证:(a) gait_test.js 第 5 组:前进时 corr(中[q]·尾[q+lag]) 峰值在 lag ≈ 284ms;(b) 第 6 组:后退时交换序列后峰值仍在 ≈284ms(相位关系确实反转)。

## 4. 避障状态机(与泳姿库联动)

```
距离 < 5cm 且不在冷却期 ──▶ AVOID(执行 C_LEFT,1.28s)──▶ 恢复原泳姿 ──▶ 2s 冷却
        ▲                                                      │
        └────────────── 距离 > 8cm 才能解除触发锁存 ◀──────────┘
```

- **滞回**:5cm 触发 / 8cm 解除,避免临界距离抖动反复触发
- **冷却**:避障完成后再等 2s 才允许下次触发,防止连续转向
- 触发时若正在执行 C_L/C_R,避障结束后回 IDLE(而非恢复转向)
- 固件端 SIM_SENSOR 编译开关可用串口注入距离仿真调试,逻辑与网页演示模式完全同构
