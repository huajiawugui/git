# 红外测距标定记录(GP2Y0A21YK0F)

## 原理

GP2Y0A21YK0F 输出模拟电压,距离近似 **d ≈ 13 / V**(cm),有效量程 10~80cm。
固件采用**两点线性标定**:实测 d1、d2 两点的电压 V1、V2,反推系数:

```
k = (d1 − d2) / (1/V1 − 1/V2)
b = d1 − k / V1
换算距离:d = k/V + b
```

标定结果写入 `firmware/config.h` 的 `IR_K` / `IR_B`。

> 电平注意:模块典型供电 5V,Vo 可达 ~2.5V。若 Vo 直连 GPIO34(ESP32 3.3V 域),建议模块用 3.3V 供电,或 Vo 经分压(如 10k+10k)后接入;用分压时电压换算要乘分压比。GPIO34 属 ADC1 通道(12bit,0~4095),WiFi 开启时务必只用 ADC1。

## 标定步骤

1. 白纸(哑光)正对传感器,分别量取 10 / 20 / 30 / 50 / 80 cm
2. 每个距离记录固件串口打印的 raw ADC 均值(固件已做 32 次均值滤波)
3. 取 **20cm 与 50cm** 两点计算 k、b(避开量程两端非线性区),写入 `firmware/config.h`
4. 用 10 / 30 / 80cm 验证,要求误差 <15%;不达标则检查供电纹波(模块 VCC 并联 100uF)或换一组标定点
